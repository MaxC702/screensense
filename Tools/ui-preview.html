ScreenBlock — UI preview

Static HTML rendering of the SwiftUI screens in ScreenBlock/Views/, using Theme from RootView.swift (bg #0b0912, card #17141f, accent gradient #7c5cff → #4a8cff). Copy and state logic are taken from the source; SF Symbols are approximated with inline SVG, so glyph shapes and system controls (segmented picker, slider, toggle, shield sheet) are close but not pixel-exact. For the real thing, run the app on a device.
