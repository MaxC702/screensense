ScreenBlock — UI preview

Static HTML rendering of the SwiftUI screens in ScreenBlock/Views/, using Theme from RootView.swift (bg #0a0d14, card #171a24, accent #4a8cff). Copy, layout and state logic are taken from the source; SF Symbols are approximated with inline SVG, so glyph shapes and system controls (segmented picker, slider, toggle, shield sheet) are close but not pixel-exact. For the real thing, run the Simulator target — commit 45ce58c added the stub path for that.
